📱 1. Overview & Flow Architecture

NtfySMS captures incoming OTP SMS messages (and optional app notifications), extracts verification codes using regex, and forwards them to ntfy or Gotify target servers.

🚀 ntfy & Gotify Nodes

Configure multiple delivery targets for public ntfy.sh servers, self-hosted ntfy instances, or Gotify push servers.

🔒 Write-Only ACL Topics

Grant NtfySMS write-only access to post OTPs (`otp-*`), while receiver apps use read-only tokens.

🔒 Tailscale / VPN Throttling

Require active VPN per node. Paused messages stay queued and auto-execute when connected.

🩺 Custom HTTP Healthchecks

Pre-flight health pings (GET/HEAD/POST) with custom headers and status codes before delivery.

⚡ 2. First-Time App Quick Start

Follow these 4 simple steps to set up NtfySMS on your phone:

⚠️ Play Protect Note: When sideloading, Google Play Protect may show a *"Blocked by Play Protect"* warning. Tap "More details" → "Install anyway".

1. Install & Grant Permissions

Sideload NtfySMS-v1.0.0.apk → Open Settings → Grant SMS Permission, Notification Permission, and Battery Exemption.

2. Add Target Delivery Node

Tap + Add Node under Delivery Target Nodes → Select ntfy or Gotify → Enter Server URL, Topic, or App Token.

3. Configure Pre-Checks & Format

Enable Require Active VPN (if using Tailscale) and test custom payload templates in the Live Tester box.

4. Activate Forwarding

Toggle top app bar switch to ACTIVE. Status notification will show 🟢 NtfySMS Active.

🚀 3. ntfy Server & Write-Only ACL Setup

Deploy ntfy (Official Repo: binwiederhier/ntfy) with Docker Compose and configure topic access control lists (ACL) so NtfySMS cannot read messages, and receivers cannot post messages.

1. ntfy Docker Compose (`docker-compose.yml`)

docker-compose.yml
version: '3.8' services: ntfy: image: binwiederhergestellt/ntfy:latest container_name: ntfy restart: unless-stopped command: [ serve ] volumes: - ./etc-ntfy:/etc/ntfy - ./var-cache-ntfy:/var/cache/ntfy ports: - "8080:80"

2. ntfy Security Hardening (`/etc/ntfy/server.yml`)

server.yml
base-url: "https://ntfy.example.com" auth-file: "/var/cache/ntfy/user.db" auth-default-access: "deny-all" enable-signup: false enable-login: true attachment-total-size-limit: "0" enable-metrics: false

3. Setting Up Write-Only & Read-Only ACL Topic Permissions

ACL Commands
# Create separate user accounts ntfy user add ntfysms_publisher ntfy user add ntfy_receiver # Grant WRITE-ONLY permission on otp-* topics to NtfySMS app ntfy access ntfysms_publisher "otp-*" write-only # Grant READ-ONLY permission on otp-* topics to Receiver App ntfy access ntfy_receiver "otp-*" read-only # Generate Access Token for NtfySMS ntfy token add ntfysms_publisher

🔔 4. Gotify Server Setup

Deploy Gotify push server (Official Repo: gotify/server) and generate Application Tokens (X-Gotify-Key).

Gotify Docker Compose (`docker-compose.yml`)

docker-compose.yml
version: '3.8' services: gotify: image: gotify/server:latest container_name: gotify restart: unless-stopped environment: - GOTIFY_SERVER_PORT=80 - GOTIFY_DATABASE_DIALECT=sqlite3 volumes: - ./gotify_data:/app/data ports: - "8081:80"
Gotify Token Creation: Log in to Gotify Web UI (`http://192.168.1.50:8081`) → Apps → Create Application (Name: NtfySMS) → Copy generated token (`A1b2C3d4E5f6`) and paste into NtfySMS App Token field.

🔒 5. Pre-Checks & Throttling Rules

Pre-checks pause forwarding when network conditions aren't met, preventing errors:

  • 🌐 Require Internet Connection: Ensures active network capability before sending.
  • 🔒 Require Active VPN: Checks for active VPN transport (Tailscale, WireGuard, OpenVPN, tun0). Pauses forwarding when VPN is disconnected.
  • 🩺 Custom HTTP Healthchecks: Pre-flight ping request (GET/HEAD/POST, custom health URL, headers, expected HTTP status) before transmitting payload.

📱 7. OEM Background Activity Settings

Prevent aggressive OEM background killers from closing NtfySMS when screen turns off:

Xiaomi / POCO (MIUI / HyperOS): Security App → Permissions → Autostart → Enable NtfySMS. App Info → Battery Saver → Select No Restrictions. Lock card in Recent Apps 🔒.
Samsung (One UI): Settings → Battery → Background Usage Limits → Never Sleeping Apps → Add NtfySMS.
OnePlus / Oppo / Realme: Settings → App Management → NtfySMS → Battery Usage → Enable Allow Background Activity & Auto Launch.

🛡️ 8. Security & Data Hardening

  • Encrypted Token Storage: Access tokens encrypted with AES-256 GCM in Android KeyStore.
  • FLAG_SECURE Screen Security: Screenshots and screen recording disabled on app screens.
  • Zero Local OTP Persistence: Verification codes deleted immediately upon delivery or expiry.
  • Cloud Backup Exclusion: Excluded from Google Drive cloud backup (allowBackup="false").

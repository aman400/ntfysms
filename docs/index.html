NtfySMS Android OTP Forwarder
GitHub Repository

Forward OTP SMS & Notifications directly to ntfy & Gotify

A personal-use, privacy-focused Android application with node-level pre-checks, VPN throttling, custom HTTP healthcheck pings, and dynamic payload templates.

⚡ Download Latest Release (APK) 📖 Read Setup Docs

Powerful Capabilities

🚀

ntfy & Gotify Target Nodes

Configure multiple target nodes for public ntfy.sh servers, self-hosted ntfy instances, or Gotify notification servers with bearer tokens.

🔒

Node-Level VPN & Pre-Checks

Require active Tailscale, WireGuard, or OpenVPN connections per target node. Unsent messages stay queued and auto-execute when connected.

🩺

Custom HTTP Healthcheck Pings

Ping target server health endpoints using GET, HEAD, or POST with custom HTTP headers and expected HTTP status codes before transmitting payloads.

🔍

Regex Variable Capture

Extract OTP codes and variables from SMS body (${code}, ${otp}, ${group1}) and sender header (${senderGroup1}) with interactive live preview testing.

🛡️

Zero OTP Local Persistence

OTP codes and sensitive message texts are deleted from the local SQLite database immediately upon delivery or expiry to satisfy security requirements.

📱

Quick Settings QS Tile

Toggle SMS forwarding ON/OFF directly from your Android notification shade with real-time status updates.

Engineered for Reliability & Security

Built with modern Android best practices (Kotlin, Jetpack Compose Material 3, Room DB & WorkManager).

🚀

Multi-Node Target Architecture

Configure multiple delivery destinations (`DeliveryNode`) supporting ntfy text/plain POST and Gotify JSON payloads with app tokens.

🔒

Node-Level VPN & Pre-Checks

Require active Tailscale, WireGuard, or OpenVPN connection per target node. Messages remain queued and auto-execute when connected.

🩺

Custom HTTP Request Healthchecks

Ping custom health endpoints (GET/HEAD/POST) with custom HTTP headers and expected HTTP status codes before dispatching payloads.

⚡

Reactive Dynamic Auto-Execution

Background 10-second polling loop and network callback listener automatically deliver queued messages the instant pre-conditions pass.

🔍

Regex Parsing & Custom Templates

Extract OTP codes and variables (${code}, ${otp}, ${group1}) with customizable format templates (e.g. `[${sender}] Code: ${code}`).

🛡️

Zero OTP Persistence

OTP codes and sensitive message texts are deleted from the local SQLite database immediately upon delivery or expiry to satisfy security requirements.
